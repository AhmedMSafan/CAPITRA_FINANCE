# CAPITRA Module Settings Manual

English and Arabic manual for Administration > Module Settings (the rules of CRM, Treasury and Factoring, each change approved by a second user).

- **Open:** [`module-settings-manual.html`](module-settings-manual.html); add `#ar` for Arabic.
- **PDF:** [`CAPITRA-Module-Settings-Manual-EN.pdf`](CAPITRA-Module-Settings-Manual-EN.pdf) and [`CAPITRA-Module-Settings-Manual-AR.pdf`](CAPITRA-Module-Settings-Manual-AR.pdf).
- **In the app:** the Help button on Module Settings opens the copy in `web/public/manuals/administration/` (keep both copies the same), in the user's language and at the open tab's section.

Version 1.0, 7 November 2026.
