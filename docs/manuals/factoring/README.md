# Finova Factoring user manual

The Factoring manual in English and Arabic, from pricing to collection: customers, the factoring calculator,
applications, the limit approval workflow (normal and fast track), the credit limit, disbursement requests, invoice
upload, Treasury disburse, claims and customer payments.

This manual is written for **Finova**: the name, titles, screenshots and logo show Finova in place of Capitra.
The application itself is not changed.

- `factoring-manual.html` — both languages (`#en`, `#ar`), screenshots in `img/en` and `img/ar`
- `Finova-Factoring-Manual-EN.pdf`, `Finova-Factoring-Manual-AR.pdf` — A4, printed from the HTML

Screenshots: `tools/screens/fct-manual-screens.mjs` (sample data, mocked API); PDFs: `tools/screens/print-manual.mjs`.
