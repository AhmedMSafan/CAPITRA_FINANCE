# CAPITRA Treasury User Manual

English and Arabic user manual for the Treasury module.

- **Open:** [`treasury-manual.html`](treasury-manual.html) in a browser. Use the English / العربية switch at the top (or add `#ar` to the address for Arabic).
- **PDF:** [`CAPITRA-Treasury-Manual-EN.pdf`](CAPITRA-Treasury-Manual-EN.pdf) and [`CAPITRA-Treasury-Manual-AR.pdf`](CAPITRA-Treasury-Manual-AR.pdf). Each section starts on a new page.
- **In the app:** the Help button on the Treasury pages opens the same manual from `web/public/manuals/treasury/` (keep both copies the same), in the user's language and at the page's section.
- **Covers:** quick start, key concepts (facility, tranche, sublimit), bank rules, debtor and supplier concentration, Step 1 Bank Limits, Step 2 Treasury Disburse, common messages, permissions, statuses and glossary.
