# CAPITRA Workflow User Manual

English and Arabic user manual for the workflow engine.

- **Open:** [`workflow-manual.html`](workflow-manual.html) in a browser. Use the English / العربية switch at the top (or add `#ar` to the address for Arabic).
- **PDF:** [`CAPITRA-Workflow-Manual-EN.pdf`](CAPITRA-Workflow-Manual-EN.pdf) and [`CAPITRA-Workflow-Manual-AR.pdf`](CAPITRA-Workflow-Manual-AR.pdf). Each section starts on a new page.
- **In the app:** the Help button on the workflow pages opens the same manual from `web/public/manuals/workflow/` (keep both copies the same), in the user's language and at the page's section: Designer and Registry section 3, Forms and Data Sources 6, My Inbox and the task page 7, Start a Workflow 8, Out of Office 9.
- **Covers:** quick start, key ideas, designing a workflow, versions, data fields, forms and data sources, working tasks, starting a workflow, out of office, messages, permissions, statuses and glossary.
