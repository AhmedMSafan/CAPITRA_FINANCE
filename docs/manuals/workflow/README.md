# CAPITRA Workflow User Manual

English and Arabic user manual for the workflow engine.

- **Open:** [`workflow-manual.html`](workflow-manual.html) in a browser. Use the English / العربية switch at the top (or add `#ar` to the address for Arabic).
- **PDF:** [`CAPITRA-Workflow-Manual-EN.pdf`](CAPITRA-Workflow-Manual-EN.pdf) and [`CAPITRA-Workflow-Manual-AR.pdf`](CAPITRA-Workflow-Manual-AR.pdf). Each section starts on a new page.
- **In the app:** the Help button on the workflow pages opens the same manual from `web/public/manuals/workflow/` (keep both copies the same), in the user's language and at the page's section: Designer and Registry section 3, Document Designer and Data Sources 6, My Inbox and the task page 7, Start a request 8, Out of Office 9.
- **Covers:** quick start, key ideas, designing a workflow (with system-built and user-defined workflow types), versions, data fields, the Document Designer and data sources, working tasks and approving requests, Start a request and My requests, out of office, messages, permissions, statuses and glossary.
- **Screenshots:** `img/`.

Version 1.0, 8 November 2026: first edition, after the K2-style additions (versions, data fields, out of office, forms and data sources).

Version 1.1, 10 November 2026: workflow types (system-built and user-defined), the Document Designer, Start a request on Home, My requests, and approving a request.
