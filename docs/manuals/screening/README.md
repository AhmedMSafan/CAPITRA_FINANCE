# CAPITRA Screening User Manual

English and Arabic user manual for Screening: the Federation Final List, member company screening and the Screening API.

- **Open:** [`screening-manual.html`](screening-manual.html) in a browser. Use the English / العربية switch at the top (or add `#ar` to the address for Arabic).
- **PDF:** [`CAPITRA-Screening-Manual-EN.pdf`](CAPITRA-Screening-Manual-EN.pdf) and [`CAPITRA-Screening-Manual-AR.pdf`](CAPITRA-Screening-Manual-AR.pdf). Each section starts on a new page.
- **Covers:** quick start, key concepts (Final List, decision types, results), signing in and two-factor, letters, decisions and their approval, the Final List and matching, member companies, licences, users and API clients, the Screening Portal, billing and GL, End of Day, Communication Center, sign-ins, audit and security, the Screening API for member companies' IT teams, permissions, statuses and common questions.
- **In the app:** a copy is served from `web/public/manuals/screening`; the Help button on each Screening, End of Day and Communication Center page opens it at that page's section. Keep the two copies the same.
- **Screenshots:** `img/en` and `img/ar`, made with sample data by `tools/screens/manual-screens.mjs`; `tools/screens/manual-images.py` turns them into the JPEGs and `tools/screens/print-manual.mjs` prints the PDFs.

Version 1.0, 22 November 2026.
