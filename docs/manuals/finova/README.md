# Finova editions of the user manuals

The same manuals as `docs/manuals/treasury`, `screening`, `workflow` and `administration`, with the same contents,
for **Finova**: the name (CAPITRA / Capitra / كابيترا) and the logo are Finova's in the text, the titles and the
screenshots. The application and the original manuals are not changed.

| Module Settings | [administration/module-settings-manual.html](administration/module-settings-manual.html) | `administration/Finova-Module-Settings-Manual-EN.pdf`, `-AR.pdf` |

The Factoring manual is Finova's from the start: `docs/manuals/factoring`.

The Overview and General Ledger manuals are Finova's from the start. Their screenshots come from a test database with sample data (`tools/screens/gl-sample-setup.sql`, `gl-sample-journals.py`, `gl-manual-screens.mjs`).
